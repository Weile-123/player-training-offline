# 渲染与发布说明

项目使用本地适配的Preact 10.29.8渲染器与 `use-sync-external-store` 兼容层，React导入通过 `renderer.config.ts` 指向同一份实现。Zustand不单独预打包，避免出现两份hooks实例。HTML／SVG结构通过本地原型节点创建；原型在 `index.html` 中定义。

## 构建与许可

`npm run build` 执行TypeScript检查、Vite构建、本地运行资源复制及审核材料生成。`vendor/preact/LICENSE` 和 `vendor/use-sync-external-store/LICENSE` 会进入 `THIRD-PARTY-NOTICES.txt`。`scripts/package-review-notes.mjs` 将本说明复制为发布包的 `REVIEW-NOTES.md`，并生成绑定当前JS哈希的 `REVIEW-EVIDENCE.json`。

构建脚本检查研究链接、旧React文档链接、HTML写入和直接网络请求等禁止项。这些本地扫描及单元测试不能代替平台正式安全审核；云网关、虎扑WebView、登录、广告与发帖仍须在目标活动环境验收。

## 验证与维护

逻辑回归使用 `npm test`，渲染回归使用 `npm exec -- vitest run --config vitest.renderer.config.ts`。真实浏览器烟测在独立上下文中执行，只使用本地样例或独立测试存档，不修改用户浏览器已有进度。

修改渲染器后应重新检查Loading到首页的动态导入、图鉴与弹窗、焦点恢复、触控和滚动。资源清单必须随生产资源重新生成；包中审核证据只对其记录的JS哈希有效。正式上传前按新版 `hupu-skills` 的交付流程取得平台审核结果。
