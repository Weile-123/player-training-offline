# 传奇球馆：当前游戏玩法

更新于2026年11月17日。经济配置为 `gymEconomyVersion: 11`，经营存档 `balanceVersion: 3`，器材目录版本3。数值以 [经营引擎](../src/game/gym/engine.ts) 和 [目录配置](../src/game/gym/catalog.ts) 为准；[旧道具配置](../src/game/gym/consumables.ts) 仅保留存档兼容。完整名图映射见 [新版器械表](新版器械表.md)，时间结算见 [离线训练实现与验收](离线训练实现与验收.md)，接入及验收缺口见 [当前状态与问题清单](当前状态与问题清单.md)。

## 经营循环与新人

从社区训练馆、0券和一名Lv.0新人开始，循环为“招募→选择计划与可选合作→投篮完成课程→获得模板→推荐→建设与收藏”。训练位等于馆级，最高8人，升级只增加空位，由玩家补招；没有自动推荐或补招。手动只训练当前选中球员，各人的经验、体力、课程、合作、冷却和自动分别保存，项目与启用器材全馆共享。

馆级大于1时，球场切换按钮始终显示，按稳定入馆顺序遍历球员及剩余空位；空位不显示上一人的资料或奖励按钮，原投篮位置改为“招募”，可直接免费招生并选中新人。查看空位期间，已开启自动的真实球员仍正常训练。名册在列表内部滚动，校友档案入口固定底部；课完成等短时提示仅在主球场显示，二级页面保留各自操作错误。

普通新人出生六维各24–48，身高178–218厘米；招生项目每级使下一人各维+1，最多+6。馆2起可选后卫178–194、锋线195–205、内线206–218的身高范围。馆6起可选每名8券精选招生：指定双维出生基础46–48，另加招生项目，不保证指定模板。免费招生保留，新人均Lv.0且未匹配模板。

## 投篮、经验与模板

有效球消耗本人1体力，手动冷却1秒。开局首人可立即出手，之后补招首球至少等1秒；切人、刷新不重置冷却。自动中的同一球员暂停手动，其他球员可继续训练。无效请求不排队、不耗体力或随机流。

| 结果 | 基础概率 | 基础经验 |
| --- | ---: | ---: |
| 维持 | 30% | 8XP |
| 成功 | 60% | 12XP |
| 大成功 | 10% | 20XP |

仅历史存档中已启用的镁粉效果继续按剩余次数保证大成功；本版本不提供新的使用入口。没有历史效果时按基础概率。通用经验器材每球+1／+2／+3XP，自动项目每级每球+1XP，自动经验器材仅在线／离线自动+1／+2／+3XP，整数相加。最高自动配置每球19／23／31XP。

Lv.L升一级需 `ceil(20+6L+0.15L²)` XP，保留结余；跨级逐级分配，每个实际等级尝试10次属性+1，抽到满99属性时该点损耗。最高Lv.99，满级关闭本人自动，停止经验、课数和体力消耗。三种结果不直接对应+0／+1／+2级。

六维为三分、中投、突破、篮下、控球、防守。保留119个模板的稳定ID、身高、等级、属性资格、相似度及峰值外观保留规则。替补／首发／全明星／巨星／传奇的最低等级为2／6／10／14／18，只到等级不保证获得模板；真实变化才揭卡，过程中解锁的模板永久收藏。

身价为 `floor(320×(L+1)³×(100+当前启用品牌百分比)/100)`，按整数算法保存字符串，不能兑换现金。历史校友保留推荐时最终身价，不按当前配置重算。

## 体力、训练计划与课程

体力上限为 `20+5×耐力级+器材加值`，最高80。每点自然恢复间隔为 `max(6,20−恢复级−器材恢复缩短秒数)` 秒，当前最高配置实际8秒。满体力不蓄积恢复时间。新人按入馆容量满体力开始；容量升级和换装不补体力，容量降低截断超额；恢复间隔改变保留已完成比例。

基础计划沿用 `0.1+bias` 抽样权重。投射计划强化三分／中投，突破计划强化突破／控球，内线计划强化篮下／防守，两项基础权重各乘2再加0.5。专项器材再加对应倾向，目标属性满99后停止额外倾向，每级总抽样次数仍为10。

每10次有效球完成一课，三种结果均计数，基础返4体力。器材额外上限按馆1–8为1／1／2／2／2／3／3／3，单课最多返5／5／6／6／6／7／7／7，再按本人容量截断。切换计划清空课内0–9球及合作器材课内进度，已完成课数保留；课程不直接发券或额外经验。

## 推荐签约与赞助券

确认页显示实际模板、身价、券、声望与明细。同一笔成功保存后球员离馆、释放空位并发奖，其他球员保持。有效模板球员保存最终校友快照；未匹配者可0券离馆，但不新增校友记录。唯一球员ID和预期存档版本防重复；失败不留下半份推荐结果。

**所有馆级从1级起统一：本馆该模板首次推荐按档次给基础0–5券；重复模板基础1券，培养、已完成合作及已取得的合作器材奖金继续相加。未匹配模板的券总额始终为0。** 升馆不重置首次资格，历史余额不回扣；旧档根据完整冷热校友最终模板补齐记录，不从图鉴推断推荐。

## 分享、广告与旧库存兼容

- 有模板、未满99且未领取的球员可分享一次等级+3，最高99；增加真实属性并更新模板，不增加训练球数和课程。
- 当前未满级球员体力为0时提供回满入口。全馆首次通过分享回满，此后通过激励广告；次数保存到存档。
- 合作广告一键完成只接受 `code=200 && data.rewarded===true`；取消、未看完、超时、旧局或旧合作回调不发奖。
- 分享先生成海报，再由玩家点击打开本项目官方编辑器，不自动发帖。仅编辑器返回 `code=200` 后执行奖励；奖励保存成功立即关闭自定义分享弹窗，失败保留提示和未领取状态。
- 球员卡无“分享·等级+3”按钮时，在档次标签前显示 `Lv.N`；有按钮时保持原排列。

本版本暂不开放消耗品，商店、背包、球场及说明中不提供购买、使用、库存或生效提示。已有库存字段和资源保留，不删除、不折券；历史已启用镁粉效果继续沿用实际剩余次数，含旧50次版本，但不能再次启用。旧字段仍参与存档读取与迁移，不代表当前功能已开放。

## 声望与球馆

入馆保存六维基线，净成长 `G=Σmax(0,最终六维−入馆六维)`；模板档序号k为待发掘0至传奇5，原始声望 `floor(G×(k+1)/10)`。课程每课+10%、最高60%，品牌按每次真实投篮的品牌均值、最高50%，只在最终统一向下取整。临推荐换品牌不回溯过去。完成合作另加固定声望，包含广告完成的合作；首次／重复券规则不改变声望。

有效推荐须正净成长及替补以上真实模板，不能按合作奖金反推。声望累计不消耗；达到培养成果后仍须逐级支付扩馆费，不足时不扣券、不升级。

## 在线自动与本地离线

馆2免费开放在线与离线自动，各球员主动开启。间隔2／1.8／1.6／1.4／1.2／1秒；模式切换保留旧冷却并至少等待新模式完整间隔，不抢额外球。

离线项目0–5级为30／45／60／90／120／180分钟，器材再加15／30／60分钟，最多240分钟。只训练开启自动且未满级者，沿用真实RNG、体力、课程、镁粉、经验与模板；超时仅恢复体力，整个区间消费后不能再领取。不自动饮用、推荐、补招或发券。

回馆事务结算并保存后显示报告，少于5秒或零球不弹窗。报告显示总经验、时长、球数、等级、课程和模板，球员横向滚动，新模板标红。基础收益已保存；可看广告额外领取一次经验，奖金不再按离线时长截断，但每名球员最多补至99级，满级不再增加或产生溢出经验。报告与实际领取数持久化，全部球员满级时禁用广告领奖；跨标签、刷新或重复回调只兑换一次，经验数字和金色动画持续900ms。并发和迁移见 [离线训练实现与验收](离线训练实现与验收.md)。

## 存档与迁移

IndexedDB原子保存经营热档主备和完整校友，`gym-management-v1` localStorage主备用作启动镜像。热档最近100人，其余完整归档；生涯和校友统计读取冷热记录，不重复相加汇总。旧合同存档独立保留。

虎扑云档使用本项目 `cloudSave.save({slot:1,value})` / `load({slot:1})`，仅手动上传与同步。设置页成功读取账号云档后允许上传；同步先比较、再确认，覆盖前保留完整本地备份。账号或本地进度变化拒绝旧确认。云档固定本项目格式、身份和白名单字段，合并全部校友，不保存其他设备的IndexedDB指针。

每份云档最多2MiB UTF-8，超限不截断必要历史；`code=200 && data===null` 才是无存档，读取失败不能当新档，空字符串按已有值校验。超时不立即重写，底层操作未结束时保持在途锁。云存档只用于恢复，不能证明可信服务端成绩。[云档协调器](../src/platform/gymCloudSync.ts) · [云档格式](../src/platform/gymCloudArchive.ts)

旧档兼容规则：

1. 缺平衡版本或版本1的当级XP按旧 `20+6L+L²` 与新需求比例换算，版本2不再缩放；等级、六维、球员、券、RNG、收藏、校友和已领奖励保留。在训体力超新上限截断，校友历史不截断。
2. 更早无XP或自动字段分别补0、关闭；旧顶层冷却和合作迁入原球员，替补补空，不凭历史球数追发经验或课程。
3. 器材V1／V2去重后迁移V3：下架按记录价全退，保留项降价退差并更新净价，涨价不追缴；同类最高档启用，其余入仓。缺购价时用保守历史估价，资源映射和收藏保留。
4. 已有V3不重复退款，项目、器材、启用和实付价保持；旧馆级免补费，项目降价不补历史差额。未结算离线先用迁移前快照结清，再启用新效果。
