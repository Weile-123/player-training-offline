# V11全馆推荐与精选招生调整

日期：2026年11月15日。经济配置11，成长与器材目录仍为3。

本版纠正此前自行加入的馆8限券条件，按用户要求从馆1起统一“同模板首次正常、之后1券”。同时将精选招生从36券试调为8券，补器材主动卸下与培养耗时预览。器材、项目、扩馆的价格与效果保持，完整建设仍为1237券；没有新增玩法，也未恢复已删除的模板推荐模块。

当前生产引擎的两种经营策略都能真实完成建设，但耗时差异很大。精选8券降低了购买负担，现有样本仍不支持它比免费招生更适合补齐图鉴。

## 全馆推荐规则

| 情况 | 实际赞助券 |
| --- | --- |
| 馆1至8，本馆首次成功推荐某模板 | 按推荐时的模板、培养和已完成合作成果正常发券。 |
| 本馆再次推荐同模板 | 每次总计1券，培养、合作和器材券不再另加。 |
| 未匹配模板 | 0券，不登记首次。 |
| 升级球馆 | 保留已推荐记录，不重新获得首次资格。 |

首次只在实际推荐成功并保存后消耗。出现模板、收录图鉴和查看预览不占首次；首次较早推荐后，提高培养或合作也不补差额。声望、属性、模板匹配与升馆成果资格照常。

已有余额和历史奖励不回扣。旧版计数与本馆真实校友最终模板合并，包含热记录和冷归档；不根据图鉴或曾出现的模板推断。读取、合并和版本标记在同一事务中提交，失败不消费首次或误发奖励。初始化只做一次，之后读取最多119个模板ID。重新开设球馆会重置本馆计数、经营余额和校友，原图鉴按既有规则保留。

代码沿用旧字段名称 `postgameRecommendedTemplates` 和 `isFirstPostgameRecommendation` 以保持兼容，含义已是所有馆级。新增玩法标记 `recommendationRulesVersion: 11`，不涉及存档恢复或备份工具开发。

## 器材与项目预览

背包中启用器材增加“移入仓库”。确认前显示移出后的实际效果，体力超过新上限会截断，并说明重新装回不补满；取消不操作。移入后可重新启用或按记录购价半价出售，已有收藏与已取得合作器材资格保留。

器材详情、替换和卸下确认增加当前球员到25级、99级的预计耗时前后对比。耐力、恢复、自动项目提供按需展开的对比；招生、器材槽、离线时长继续使用对应实际作用说明，不虚构等级提速。

预览沿用当前体力、课程、冷却和手动／自动模式，复现引擎容量截断与恢复进度缩放，不消费随机数。25级已完成时只显示99级；99级或无球员时明确说明。预测不保证模板、属性或随机完成时间，也不计算停留、饮料、后续换装与下一名新人的满体力开局。

比较只在详情、确认或项目展开时计算，避免同时给35张货架卡运行长训预测。恢复效果和售价保持原配置，玩家可按自己的培养路线选择。

## 精选8券

馆6开放，每名8券，手动身高和方向选择、两项出生基础46至48、招生项目另加的保证保持。其余出生属性、天赋与成长不变，不赠送经验、等级或指定模板。免费招生保留。

产生重复模板时，精选净消耗7券。这是实际收支，不代表8券已经被证明对所有玩家划算；精选定位为改善开局和较高档模板概率，不保证新增图鉴。

早先追传奇满建状态的四条一小时对照也保留：免费净增450／510券，混合净变动+1／−3券；混合花456／528券，新增图鉴3／4，免费1／3。两种起点历史不同，不能混为同一人群。

### 1536名受控新人

128种子、三个方向、招生项目0／6、免费与精选配对共1536人。实验仅在这部分预置合法馆级、基础设施和8券，检验出生优势，不作为建设可负担性的证据。实际招新后不注入属性、模板或训练成果。

方向出生均值增加约10.24至10.66，10级仍多9.65至10.46，25级缩至1.79至3.68。各组128对中91至103对最终模板相同；精选25级传奇人数多5至9人。较高出生也会跳过低档模板，收录并集不一定更多。结果支持改善开局，尚不支持“付费更容易补全图鉴”。

## 合作与推荐弹窗精简

赞助合作移除无关余额、重复介绍、同义目标描述和逐项进度条。合作卡保留实际奖励、训练／课数、具体模板档次与专项属性门槛，器材资格压缩显示；计算规则收进“？”合作说明。当前重复模板明确券不叠加，更换／放弃仍确认清空进度、未领收益与器材资格，满级及待确认保护保留。

推荐签约主界面突出实际券与声望，培养成果压缩为一行，删除重复的完整培养建议。券／声望分项和六维放进默认收起的结算明细，规则与培养加奖表从“？”查看。首次之后不补差额、重复1券、未匹配0券、未完成合作在推荐后结束，以及离馆与免费补招均保留短提示。
