## 原版名图复用

已查看原版96张器械图：94件在售、2件停用。消耗品与招募卡不计作器械。新35件采用35组不同、在售的原版名称与图片，不再给旧图片套自创名字；尽量按外形、动作及用途匹配。

例如自动经验三档使用“基础投篮机、回响投篮机、超频训练机”；通用经验使用“传承笔记、投篮动作记忆器、冠军训练传承书”；离线时长使用“训练计时器、巅峰时刻计时器、火热延时表”。六维专项选择投篮手套、校准器、动作板、突破指南、反弹训练器、护具等最相近资源，具体作用由类别和效果说明列明。

名称和图片来自同一个原版条目；游戏沿用已有优化图像，没有重新绘制或覆盖原图、CSS、按钮及项目技能包。资源图像与原版身份一致，不宣称优化文件与原文件字节完全相同。

存档逻辑ID保持35件原有身份，新增独立 `artId` 选择原版名图。购买、仓库、替换、出售、收藏仍使用逻辑ID；仅经营版商品、详情、馆内槽和图鉴使用图片ID。无需重置、重新退款或迁移当前V3存档，原版模式的共用图片组件保持原映射。

完整内容见[新版器械表](新版器械表.md)、[CSV](器材汇总.csv)、[原96件资源索引](原版器械资源索引.csv)、[35件图文对照](evidence/equipment-original-reuse-v3.png)。Excel已同步名称与图片ID，并增加35张原图缩略对照，原成本公式和92行训练试算保留。

## 为什么不靠统一涨价解决积券

从零均衡路线到馆8平均结余约1140.16券。其中确实有未购永久内容，但按现价补满六项目、买齐所有尚未持有器材、连已卖出的低阶也买回后，三条器材投资路线共96个样本仍平均剩610.36券。

因此积券不是单纯“脚本没买齐”。永久商品买一次，推荐收入可继续产生；普涨只能推迟买齐，并同时抬高前中期门槛。需要让券在长期培养中持续有用途，而非只增加一次性标价。

## 推荐方案：36券精选招生

在现有招募中增加一个自愿付费选项，不新增货币或维护费：

| 规则 | 建议 |
| --- | --- |
| 开放 | 球馆6级，普通免费招募继续保留 |
| 收费 | 每名精选新人36券，一次性支付 |
| 方向 | 复用投射、持球突破、内线防守三个既有方向，对应三分/中投、突破/控球、篮下/防守 |
| 品质 | 对应两项出生基础值保证46–48；原本已在该区间的值保留，已有招生项目照常叠加 |
| 其余 | 其他出生值、身高分组、成长偏好按原规则；不额外送经验、等级、每级点数或必得模板 |
| 位置 | 仍需现有空训练位，不能付费突破最多8位 |
| 操作 | 玩家主动选择；确认前写清36券和保证内容，取消不扣券；离线不自动招募、不自动消费 |

当前免费出生基础区间24–48，已有招生项目加在其上。精选保证仍在正常出生上限以内，不建立另一套属性或模板算法。它的用途是用积攒的券换取更稳定的定向底子，帮助球星收集；免费培养仍可正常推进。

不采用“只收费指定精确身高”：119个模板中107个通过已有免费身高分组就能100%满足身高区间，19传奇中18个如此；匹配算法也没有“更靠近标称厘米就额外提高相似度”的规则。单靠精确厘米不足以证明36券的价值。

### 消耗为什么不会形成产券套利

当前单人推荐总回款最多33券，收费36券。因此无论养到什么模板、选择什么合作与器材，该付费球员从招募到推荐的净券变化都不超过−3券；直接放弃或低回款则净消耗更多，最多36券。

这条上界来自当前真实奖励规则，不依赖平均概率。如果以后提高单人最高推荐收入，必须同步重算收费，不能直接沿用36券。

普通招募、精选招募、培养推荐形成选择：需要资金时培养免费新人，追求定向收藏时投入积券。更高出生值会从培养声望基线中扣除，不能购买新人后立刻推荐来刷声望。

## 已做的方案影子试验

只在实验分支调整出生值，**没有实现收费流程，也没有改变游戏招募**。128个种子×3训练方向，每对保持身高、偏好、随机流、配装和项目一致，比较免费与精选假设，共768条轨迹、208,776球、3768次真实推荐账本探针。

固定馆6项目：耐力2、恢复4、招生2、器械1、自动2、离线0；使用58券供给配装，不使用合作加券器材。从出生接基础合作，采用对应训练计划，实际引擎成长与原模板匹配。

影子配对规则为：基础值已≥46则保留，否则设为`46 + 原基础值%3`，然后加招生项目。它在25个可能基础值中映射成46/47/48的数量9/8/8，均值46.96；这是为了保持确定配对的试验规则，不冒充未来已经实现的均匀随机招生。正式生成规则需在落地时明确并复测。

| Lv25指标，每组128人 | 免费 | 精选假设 |
| --- | ---: | ---: |
| 投射两项都≥90 | 89 | 114 |
| 持球两项都≥90 | 79 | 109 |
| 内线两项都≥90 | 73 | 109 |
| 投射传奇 | 11 | 19 |

所有对应等级节点的球数、时间完全相同；Lv25平均约183.92球、331.93秒。精选改善出生定向底子，不赠送升级速度，不保证传奇或指定球星。

| Lv25，假设付36券 | 平均推荐回款/券 | 平均净消耗/券 | 平均培养声望：免费→精选 |
| --- | ---: | ---: | --- |
| 投射方向 | 15.97 | 20.03 | 157.85 → 153.39 |
| 持球方向 | 13.97 | 22.03 | 147.45 → 144.34 |

声望与净成长略低，是更早碰99及出生值不计培养增量的结果。无效属性抽样相应增加，不应宣传为所有收益全面提高。该表只代表此固定阶段和基础合作，没有拿24券样本上限替代全游戏33券上界。

## 实际余额能支持多少投入

使用已有96条真实馆8余额，先补齐所有永久内容，再保留100券，不预支未来推荐回款：

| 路线 | 可先支付的精选人数均值 | 样本范围 | 支付后余额均值/券 |
| --- | ---: | --- | ---: |
| 均衡 | 13.78 | 12–16 | 115.78 |
| 供给 | 13.50 | 12–16 | 121.00 |
| 经营 | 13.72 | 12–17 | 118.31 |
| 合计 | 13.67 | 12–17 | 118.36 |

“人数”是财务上分批可支付的数量，不是同时招入13人；每次仍要有空位。平均预付款492券不等于销毁492券，球员后续推荐会返券。实际净消耗应扣回款；本次Lv25影子结果每人约净耗20–24券，最高收入边界则至少净耗3券。

这证明方案能提供有培养价值的重复消费出口，不能证明所有玩家都会使用，或玩家同时继续培养免费球员时总余额一定下降。免费无限筛选仍可追求同样出生上段；理想均匀独立模型下，两项同时≥46概率1.44%，期望筛69.44名、约137.89条招募/丢弃命令，付费价值包含减少筛选与提高定向稳定性。
