# 器材与项目调整实施说明

日期：2026年11月14日。当前经济配置为 `gymEconomyVersion: 7`。V6接入了高阶器材价格与馆级、耐力和招生的升级价，以及离线饱和预估提示，但总标价从810降到727券，实测补齐后平均余额从611.91增至692.47券，反而扩大了冗余预算。V7保留单项性价比校准，新增累计510券扩馆费用，完整建设标价变为1237券；培养奖金和合作奖励保持。[扩馆规则、原型对照与局限](球馆扩建费用与经济纠偏.md)单独列出。

所有项目仍需逐级购买并满足馆级上限，项目效果与最高等级保持。耐力每级仍只增加5点容量，不补充当前体力；招生每级仍只提高下一名新人的六维出生值各1点。经验曲线、升级属性点数、模板匹配、培养奖金与合作奖励保持。

## 离线升级提示

离线课表升级时，按当前开启自动的球员和配装预估到99级所需时间，提示全员或部分可能在现有时长内提前满级，延长时长不一定增加本批收益。它是当前配置下的预估，不保证随机训练结果，也不强制阻止购买。

永久课表仍适用于后续球员；购买后可以换下加时器材，保留课表时长并释放器材槽。提示不改变离线帽、每球经验、99级停止或超时只恢复体力等结算规则。

## 旧档兼容

本轮没有更改存档结构或器材效果，`balanceVersion: 3`、`equipmentCatalogVersion: 3`、`offlineRulesVersion: 2` 保持。经济配置版本7是购买及扩馆规则修订，不触发已有V3档的器材目录迁移。

- 已购项目等级、馆级、持有器材、启用状态、球员、券、声望、收藏和历史档案保留。旧已达馆级免补扩建费，现金和已领历史奖励不回扣；之后升级按当前价支付。新器材馆级门槛只限制以后购买，不回收或停用已有高阶器材。
- 不补发历史项目降价差额，也不追收已购器材涨价。已有器材保留原记录实付价，仓库出售仍按该记录半价向下取整；新购或卖出后重购按当前价格扣券并记录。
- 更早V1/V2目录仍沿用原先迁移：下架退款、保留项降价退差、同类整理与未结清旧离线快照等规则不与本次购买价修订混为一轮。

V6正式落地后曾执行[32种子经营验证](balance/acquisition-v6-20261114.json)：32/32在24小时模拟上限内达到馆8，中位41,682.84秒（约11.58小时）；补齐全部永久内容后平均692.47券。每个种子均匹配实施前组合候选，验证了接入正确，却也确认只降单项价会扩大闲置预算。它保留为V6历史基线，V7结果见[经济纠偏报告](球馆扩建费用与经济纠偏.md)。

36券精选招生仍为方案，没有增加收费招募、自动推荐、自动招募或其他重复消费玩法。扩馆费是一次性建设支出，可降低满馆阶段盈余，无法消除无限免费招募和持续推荐在所有建设完成后的继续积券。

V7正式基础合作32种子全部到馆8并实际补齐，补齐后平均181.69券，范围128–262；到馆8中位42,806秒。匹配较高合作时32种子均到馆8，但只有8条当刻足以买齐，其余继续培养后32/32实际补齐，最终平均19.50券；额外推荐平均1.91名、最多4名。到馆8时的预算缺口与续跑后的真实余额分别记录，详见[正式验证](球馆扩建费用与经济纠偏.md)。领域回归1,080项通过、另1项原有跳过，渲染回归114项通过。
