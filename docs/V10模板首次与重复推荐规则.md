# V10模板首次与重复推荐规则

历史记录：此版本错误地将限券限定在馆8。用户要求的是所有馆级统一首次正常、之后1券，现已由[V11全馆规则](V11全馆推荐与精选招生调整.md)替代；下文的建设与收益数据只属于旧规则。

日期：2026-11-15。经济配置版本10，成长与器材目录保持版本3。

按用户选择，将V9的500券发放线替换为“同一模板首次正常、之后1券”。本轮沿用后期范围：馆1–7保持原规则，馆8按下面规则结算。随后按用户要求移除了游戏内模板目标推荐模块；价格、成长、声望和图鉴规则保持。

## 当前结算规则

| 场景 | 实际赞助券 |
| --- | --- |
| 馆1–7推荐 | 原有模板、培养与已完成合作奖励 |
| 馆8阶段首次推荐某个模板 | 按该球员当时实际成果正常发券 |
| 馆8阶段再次推荐同一模板 | 总计1券，培养、合作与合作器材券不再另加 |
| 未匹配模板 | 0券，不登记首次 |

“首次”指本座球馆的馆8奖励阶段。此前馆1–7的推荐不占首次，图鉴收录和模板出现也不占首次；只有成功推荐结算才登记。已有馆8旧档从本规则更新后开始记录，不追溯扫描历史，不回扣已领取的券。重新开设球馆后，新馆独立记录。

同模板第一次较早推荐也会使用首次正常奖励资格，之后即使等级、培养奖金或合作提高，都不补差额。推荐界面在确认前明确提示，玩家可以选择继续培养后再推荐。如果最终模板变成另一个尚未在馆8阶段推荐过的ID，则按该新模板正常结算。

余额不再设500券发放线，超过500也可以继续获得首次或重复奖励。声望、培养属性、收藏与有效推荐资格照常，器材售价、项目价格、扩馆费用及36券精选价格均保持。完整永久建设仍为1237券。

## 界面与玩法记录

推荐面板区分理论培养成果与实际入账，重复时列出结算调整及合计1券，确认按钮和校友记录使用实际券。首次确认前提示后续不补差额，重复模板的培养建议也不再承诺“下一奖金再增加N券”。

合作面板保留理论奖励和达标条件，但说明重复模板的实际券总计不再增加；合作声望正常。精选招生在满馆时提醒：若最终产出已推荐模板，仍支付36券、推荐仅回1券。

玩法状态只增加一份最多119个模板ID的记录。预览不消耗首次，推荐保存失败也不消耗；成功结算后跨页及重载保留。此次只增加玩法计数及其验证，没有处理用户要求后置的存档恢复或备份问题。

## 验证与经济含义

在冻结V8引擎的独立原型中，4/4种子从零真实买齐全部建设，每条实际支付1237券（其中扩馆510），买齐后余9–31券，未出现规则导致的断粮。正式V10另复核2条从零建设和4条精确1小时路线，逐项账本与对应原型一致；阶段首次记录从到达馆8一直保留到买齐及后续路线，没有在长跑起点清空。

| 买齐后精确1小时 | 种子1 | 种子2 |
| --- | ---: | ---: |
| 免费路线实际净增券 | 948 | 996 |
| 免费路线末余额 | 967 | 1005 |
| 混合精选实际消费 | 936券 | 936券 |
| 混合路线实际净增券 | −1 | 18 |
| 混合路线末余额 | 18 | 27 |

以上为持续在线、即时管理、练到实际Lv25即推荐的压力测试，不代表普通玩家每小时收入。两个种子的首小时含57/62次阶段首次奖励，不能外推成长期固定增速；原型与正式复核复用种子，也不能相加当作独立玩家样本。

规则降低的是重复推荐的单次收入，仍允许每次1券持续积累。本次Lv25策略约215次推荐/小时，全部重复时约215券/小时；更早推荐可能更快，因此215不是刷券上限。每模板最高正常回报33券时，阶段首次相对每次1券的额外奖励总量最多为`119×32=3808`券。

精选最终若推荐重复模板，则净消耗`36−1=35`券；全部依靠重复推荐时，需要35次1券收入补回这笔净消耗。精选的出生保证未增强，不能据新收费消耗推断其收藏价值提升。

全量1160项逻辑测试、132项界面测试通过，另1项原有跳过；TypeScript与生产构建通过。验收包含首次／重复／新模板、未匹配、等级或合作提高不补差、超过500仍入账、旧档缺省计数、保存失败重试、重复ID及非法ID拒绝、前期推荐不消耗后期资格，以及奖励明细和培养建议一致。

## 后续复查

同日复核当前结算与目标提示，42项逻辑专项通过。发现并修正目标面板的99级提示遗漏：训练已结束时，路线改为供下一位新人参考，明确差距基于当前球员，隐藏当前训练按钮；98级仍可训练，已获得目标不再提示待补差距。修正后12项相关界面测试、TypeScript与生产构建通过。

此次未调整奖励或价格。重复1券仍会鼓励更早推荐，精选产生重复模板时净耗35券；这些是当前规则的体验取舍，下一阶段应先实际试玩观察，不据此继续增加复杂玩法。

再次审查修正两处满级资源问题：99级禁止新接、更换合作，保留已有合作、器材资格和推荐结算；98级打开更换确认后升到99级，确认也会禁用。99级不能使用运动饮料，主场、背包和商店入口均给出说明，购买仍可留给其他或未来球员；98级正常接换合作、使用饮料，主动放弃合作仍沿用原确认流程。

修正后全量1167项逻辑测试、144项界面测试通过，另1项原有跳过；TypeScript与生产构建通过。验证覆盖满级拒绝时不改变合作、器材资格、饮料数量及实际首次／重复推荐奖励，以及98级到99级的确认边界。

目前最明显的奖励范围问题是：馆1–7不记录重复，玩家可停在馆7持续正常赚券，再带余额升馆8；此前推荐过的模板在馆8仍可正常领一次。不能据馆8重复限额认定全流程冗余已经解决。后续若调整范围，需同时复测早期扩建和器材购买速度。重复1券偏向尽早推荐、36券精选的收藏收益在现有样本中有限，仍需用现有规则与价格验证，暂不新增玩法系统。
