# 训练馆流程与数值复审

此记录对应V10审查。全馆推荐范围、精选价格、器材主动卸下与耗时预览已由[V11实施与复测](V11全馆推荐与精选招生调整.md)更新；下文旧规则模拟保留作问题定位，不能直接代表当前收益。

日期：2026年11月15日。经济配置版本10，器材目录与成长版本3；已移除模板目标推荐模块。

本地训练馆的核心经营闭环已打通：可以从零培养、推荐、升级到8级并买齐建设，随后继续免费或精选招生、培养和收藏。本轮未发现新的负券、重复结算、球员丢失或主线资金死锁，但确认两处操作与边界缺口，以及三项后期数值问题。流程可完成，数值仍需调整。

本轮仅审查并保存证据，未修改生产玩法、价格或奖励。存档恢复与备份仍按用户要求后置。

## 确认的操作与边界缺口

### 启用器材无法主动移回仓库

引擎已有 `unequip` 操作，但背包中启用器材仅显示禁用的“馆内生效”，没有卸下入口。启用器材也不能直接出售；玩家必须先找另一件替换，才能将旧件移回仓库。这与项目面板建议“换下离线加时器材，腾出槽位”的提示不一致。

最小复现：馆2购买唯一一件2券离线器材后余额为0，背包中无法主动停用或出售；同一状态直接执行现有卸下、出售操作合法，返1券。它不使升馆主线卡死，但妨碍腾槽和回收资金。

位置：`GymPanels.tsx` 启用器材按钮与背包列表，`engine.ts` 的 `unequip`、`sell-equipment` 分支。

简单处理：在背包的启用器材卡上补“移入仓库”，复用现有效果预览；降低体力上限时提示当前体力变化。无需新增系统。

### 临近满级仍可接入必定无法完成的合作

目前只在99级拒绝新接、更换合作。98级只剩1经验时仍可接基础合作，下一球必到99级，新合作却只完成1/10球，之后无法继续。若从已完成合作更换，原合作的奖励与器材资格按现有规则清除；正常首次结算的一个复现中，券由33降至23。

更换前已有清空进度的确认，因此不是无提示扣奖励；缺口在于允许玩家接入确定无法完成的目标。重复模板的券仍受1券规则限制，不能把33降23的例子套到所有结算。

位置：`engine.ts` 的 `accept-cooperation` 分支，`GymPanels.tsx` 的合作接取和更换确认。

简单处理：只对确定无法完成的情况补校验，按剩余经验与最低单球经验计算最多可投次数，结合当前课进度核对合作球数、课数；不足时禁用并说明。接取后改变经验配置也需保留实际达成判断，不能承诺一定完成。

## 数值与玩法取舍

### 馆7和馆8之间存在奖励断层

重复限制只在馆8生效，馆1至7既不减少重复奖励，也不占用馆8首次资格。正常25级传奇、不计合作为23券；停馆7可以重复获得，升馆8后相同模板首次正常，之后合计1券。玩家存在停馆7攒券的经济动机。

重复1券同时削弱了同模板继续培养和完成合作的券收益；若最终仍是重复模板，纯赚券时更早推荐更有利。声望、属性、收藏纪录仍有价值，但不能抵消全部玩家对投资回报的关注。

后续应先核对重复奖励的统计范围，再复测前期建设速度。直接把现有1券规则扩到前期，可能改变当前可完成的建设节奏，需要独立验证。

### 成熟短周期下部分高阶投入没有速度收益

16个种子的配对测试使用合法馆8合成阶段、满级项目、八类非专项高阶器材、配置后免费招生满体力、基础训练、满级自动与两类最高经验器材。每个种子分别比较8种配置。

练到25级的实际耗时为133至138秒。自然恢复或课恢器材降中档、移除其中一类恢复器材、恢复或耐力项目8降7、容量器材降中档，均16/16没有比对应满配变慢；移除课恢器材的新人到25级仍余11至15体力。新人满体力入馆，使这类短周期不需要等待恢复。

它们仍有长训效果：单种子到99级对照中，满配7750秒，中档自然恢复9686秒，中档课恢10518秒。因此不能判定器材失效，也不能外推为所有阶段无收益。问题是后期重复1券偏向短周期，而高阶恢复投入主要服务长训，两种激励存在冲突。

不宜用普遍降价或单纯涨价消耗券来处理。应先选定现有培养循环的目标，再调整对应的价格、解锁或效果；无需增加新玩法。

### 精选36券的收藏优势尚不充分

本轮一个种子的满建后1小时对照中，免费路线新增21个图鉴、净增948券；混合精选路线支付936券、新增22个图鉴、净变化负1券。两条均215次推荐，但精选会改变招生随机流，不能当作相同出生的严格配对，也不能认定所有玩家只多1个图鉴。

确定的是：精选产生重复模板时净消耗35券。现有样本支持它能消耗余额，尚不足以证明36券普遍值得购买。后续只需验证现有出生保证和价格的关系。
