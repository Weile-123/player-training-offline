# 王牌训练师训练馆经营版

当前入口为经验成长与多球员训练馆经营版，基础体力为 20。手动只训练选中的一名球员，消耗其 1 点体力，冷却 1 秒；之后补招的新人首球也至少等待 1 秒。维持／成功／大成功概率为 30%／60%／10%，分别获得 8／12／20 XP；Lv.L 升一级需 `ceil(20+6L+0.15L²)` XP，每级沿用原算法尝试分配 10 点属性，最高 Lv.99。详细规则见 [游戏玩法设计方案](docs/游戏玩法设计方案.md)。

训练位数等于馆级，Lv.1 一位，Lv.8 八位；开局一人，新增空位由玩家免费招募。Lv.2 需累计 60 声望与两次有效推荐，同时免费解锁在线自动与30分钟离线训练，基础2秒／球；自动项目每级缩短0.2秒并使自动每球额外获得1XP，五级为1秒／球、每球额外5XP。离线课表五级依次扩到45／60／90／120／180分钟。各球员分别保存经验、体力、课程、合作、冷却和自动状态，自动中的同一球员暂停手动投篮。离线只训练开启自动的球员，沿用器材、课程和经验规则；超时只恢复体力。没有自动推荐或自动招募。

保留四种训练计划、十球课程、可选赞助合作、八级球馆、六类项目、运动饮料、背包、校友与双图鉴。器材库V3为35件、14类，当前经济配置版本11，总标价328券；全馆共享，每类只启用一件。覆盖容量、恢复、课程、通用经验、自动经验、离线时长、品牌、合作与六维专项。每课基础返4体力，器材追加上限随馆级为1／1／2／2／2／3／3／3。推荐基础档位券仍为0–5；培养奖金取“Lv.10+首发3券、Lv.15+全明星7券、Lv.20+巨星12券、Lv.25+传奇18券”满足的最高累计档，加已完成合作与器材，总券最高33。六项目满级共399券，连同全部器材标价727券；升馆2免费，升馆3至8分别付10／20／40／80／140／220券，扩建累计510券，完整建设标价1237券。

器材有空位且无同类时买入即生效；已有同类或位置满时先确认替换，旧件入仓。仓库可装回或按记录实付净价半价出售，售后图鉴保留。合作器材需实际启用完成两个完整10球课程，资格取得后换下仍保留；品牌声望按实际培养均值精确结算。离线器材延长15／30／60分钟，连同项目最多240分钟，每球经验与在线自动一致。更早V1/V2目录迁移继续按下架退款、降价退差及旧离线快照规则处理；本轮已有V3档保留项目、器材与实付购价，不追收涨价、不补发历史项目降价。完整清单见[新版器械表](docs/新版器械表.md)，本轮变更见[实施说明](docs/器材与项目调整实施说明.md)。

35件名称和图片逐件复用原版成对资源，逻辑ID与原图ID分别记录。V6将最高自然恢复改为30券／馆7、最高课后恢复36券／馆8、最高通用经验仍20券但在馆7开放；耐力逐级价为1／2／3／5／7／10／14／20，招生为2／4／7／10／14／20，离线项目增加提前满级预估提示。该轮把原810券降为727券，实测补齐后平均余券从612增加到692，未达到减少冗余券的目标。V7保留这些单项性价比调整及培养奖金，通过[球馆扩建费](docs/球馆扩建费用与经济纠偏.md)增加与训练位、项目上限和器材资格对应的建设投入。旧已达馆级免追收，现金和历史奖励不回扣。V8已实现[收藏目标、36券精选招生与长期校友归档](docs/V8后期收藏与长期存档开发说明.md)。免费招生保留，精选在馆6开放；主动消费能花出积券，但不保证免费经营余额停止增长。

身价采用 `320×(L+1)³` 再乘器材百分比，不再逐球大成功复利。离线与旧档规则见 [离线训练实现与验收](docs/离线训练实现与验收.md)。培养奖金与自动效率此前已落地，配对试算见 [培养收益与自动效率调整报告](docs/培养收益与自动效率调整报告.md)。原 [培养收益优化方案](docs/培养收益优化方案.md)保留提案与V4复审背景；旧价格数值见 [11月12日测试报告](docs/经验成长与多球员训练测试报告.md)。训练计划保留课程、六维与方向选择；合作卡显示必要目标和奖励；推荐页突出实际券与声望，结算明细按需展开。详细规则从“？”查看。

当前支持本地在线与离线训练，Timeflow服务端、双榜和其余四种消耗品未开放，生产上报仍需相应后端与验收。[11月12日全流程审查](docs/游戏全流程审查报告.md)保留为历史基线，不能将其中旧价格和离线未开放的结论套用于当前版本。

[11月14日V7全流程与数值复审](docs/V7全流程与数值复审.md)覆盖广策略经营、119模板可达性、离线与并发、长期存档和后期经济。该轮修复了超大存档覆盖后无法读取的问题，并发现后期积券与历史增长；V8已按此实现收藏目标、可选重复消费与历史归档，正式效果及限制见开发说明。

当前已移除游戏内模板目标推荐，包括目标选择、下一档候选、属性缺口、培养路线与招生自动联动；点击球员头像查看当前资料，图鉴和推荐签约结算保留。V11纠正了此前错误加入的馆8限制：所有馆级从1级开始，同模板在本馆首次推荐正常发券，之后每次合计1券，未匹配0券；升级不重置资格，旧余额和已领券保留。首次按当时成果计算，后续培养或合作提高不补差额。精选招生改为8券，出生保证不变；背包支持移入仓库，器材详情与确认预览可比较到25／99级的预计耗时。恢复效果与价格不变。当前规则与验证见[V11说明](docs/V11全馆推荐与精选招生调整.md)。V10仅馆8的规则与数据保留为[历史记录](docs/V10模板首次与重复推荐规则.md)，不能代表当前全馆规则。

## 本地运行

```sh
npm ci
npm run dev
```

使用Node24（本轮验证环境）。开发地址为 [127.0.0.1:5174](http://127.0.0.1:5174)。已有 `node_modules` 时可直接运行 `npm run dev`。运行 `npm run build` 后使用 `npm run preview` 查看生产构建，预览地址为 [127.0.0.1:4174](http://127.0.0.1:4174)。

常规回归使用 `npm test`，渲染回归使用 `npm exec -- vitest run --config vitest.renderer.config.ts`。当前器材试算使用 `node scripts/run-gym-equipment-balance-v3.mjs`，默认64种子；追加 `offline` 重跑离线饱和试验。从零经营使用 `node scripts/run-gym-equipment-v3-journey.mjs`，当前新库与旧库历史数据在 `docs/balance/experiments.json` 中区分。运行 `node scripts/export-gym-equipment.mjs` 可重新导出当前表与CSV。

## 项目配置

游戏使用本地美术；浏览器IndexedDB原子保存经营热档主备与完整校友历史，`gym-management-v1` localStorage主备作为启动镜像。当前平衡标记为 `balanceVersion: 3`、器材目录版本3，经济配置为 `gymEconomyVersion: 11`。扩馆在同一笔成功操作中扣券并升一级；余额不足不扣券、不升级。旧已达馆级免追收，之后按当前扩馆费升级；器材、项目、现金和已领取奖励保留。V8新增可选收藏目标与历史归档字段，校友无损分离、热档保留最近100人；器材效果沿用原配置。旧档已拥有、已启用的高阶器材保留，新馆级门槛只限制后续购买。已有档先校验旧 payload：缺失平衡版本或版本 1 的当级 XP 按旧、新需求比例映射，版本 2 不再缩放 XP；旧在训体力超出新容量则截断，校友历史体力保留。原等级、属性、球员、券、声望、项目、RNG、图鉴与校友保持，不追发升级或历史奖金。更早无 XP 的档补 0、无自动的档补关闭，旧冷却与合作迁入原球员，新增训练位保持空位。旧馆级与项目不回退，历史购买不追溯重算。原版合同存档继续保留在原键，平台技能以项目内 `hupu-ai-game-skills` 为准。

球员肖像与资料沿用已有虎扑适配与本地回退。新模板会从经营收藏恢复上报队列。正式模板上报使用 `VITE_GYM_API_BASE` 与 `VITE_GYM_ENV_ID`，需接入对应活动的统计后端。本地开发只记录收藏，部署时通过安全环境配置提供服务地址与活动环境。
