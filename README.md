# 传奇球馆

本地在线与离线均可游玩的篮球训练馆经营游戏。当前入口为训练馆版，支持八级球馆、多球员培养、35件共享器材、六类经营项目、推荐签约、校友归档与收藏图鉴。运行规则见[游戏玩法设计方案](docs/游戏玩法设计方案.md)，平台部署缺口和本轮审查结果见[当前状态与问题清单](docs/当前状态与问题清单.md)。

## 本地运行与验证

```sh
npm ci
npm run dev
```

开发服务为 http://127.0.0.1:8800；生产构建使用 `npm run build`，预览使用 `npm run preview`（端口4174）。

```sh

npm run build
```

排行榜云函数有独立依赖：在 `activity/cloudfunctions/activity_api` 执行 `npm ci`、`npm test`。本地测试不能代替平台验收；当前后端部署、H5审核和真机验收状态见[状态清单](docs/当前状态与问题清单.md)。

## 当前玩法

- 手动训练选中的一名球员，每球消耗1体力、冷却0.5秒；维持／成功／大成功概率为30%／60%／10%，获得8／12／20基础经验，最高2000级。
- 首次开馆进入独立新手练习，依次体验招募、两次升级、模板解锁、推荐奖励与扩馆；中途跳过需确认。设置仅保留“重玩新手引导”，不再提供关闭首次练习的开关；旧关闭偏好不影响首开。练习不写入正式球馆、云存档或排行榜。
- 训练计划、课程与赞助合作从球馆1级即可使用，首次打开相应页面时提供短引导。
- 训练位上限大于1时，球场切换按钮遍历所有球员与空位；空位的主按钮可直接免费招募并选中新人。名册列表内部滚动，校友入口固定在底部。
- 体力回满与切人按钮同时出现时，回满位于切人上方；单独出现时仍在球场右下角。操作与错误提示自动显示3秒。
- 球馆2级开放自动训练和30分钟离线训练；项目与器材可扩展至最多240分钟。离线沿用逐球随机、课程、体力和器材规则，不自动推荐或招募。见[离线实现](docs/离线训练实现与验收.md)。
- 同一模板首次推荐按实际培养成果结算；后续推荐的基础券为1，培养奖金、已完成合作与取得资格的器材奖金继续叠加；未匹配模板为0券。精选招生每名8券，球馆4级开放。
- 本版本暂不开放消耗品，商店、背包和球场均不显示购买、使用或库存入口；旧库存及历史已启用效果保留兼容。
- 分享升级每名球员一次、加3级且不超过2000级。体力奖励首次通过分享、此后通过广告；合作支持广告一键完成。只有编辑器打开／广告成功以及奖励持久化均确认后才算领取成功。

器材名称、效果、资格和价格统一见[新版器械表](docs/新版器械表.md)与[器材CSV](docs/器材汇总.csv)。`npm run export:equipment` 可重新导出当前表。

## 存档与平台能力

浏览器IndexedDB原子保存球馆主备与完整校友历史；localStorage保留启动镜像。热档保留最近100名校友，冷历史分页读取。旧档迁移保留合法进度和已领收益，不追收历史扩馆费。

虎扑接口只采用根目录 **hupu-skills/** 的当前契约，公开应用身份读取其 activity.json。凭据只供可信服务端使用，不导入前端、静态资源或日志。训练馆云档使用新版 cloudSave.save/load 的1号位，手动上传与确认同步；超过2MiB时明确拒绝上传并保留本地数据，不截断完整历史。合同版旧存档保持独立。

当前主游戏采用local-first：训练、推荐和离线收益由本机逐球引擎与事务存档结算，不等待云端账号或Timeflow返回。Timeflow保留兼容权威链路及后台校时能力，没有接管当前主玩法；其真实平台六组回放、事务与异常恢复已有验证记录，见[离线实现](docs/离线训练实现与验收.md)。

用户信息、反馈、海报发帖、广告及离线双倍经验已接入；分享与广告按官方native SDK确认并保存领取状态。身价／声望双榜通过 `gym-local-progress` 提交包含完整校友历史的白名单档案，服务端计算身价、核对声望并保留账号历史最高纪录；账号身份取自平台网关，不接受客户端自报PUID或分数。此来源标记为 `local-validated`，与保留兼容的canonical历史区分；同步榜单不会覆盖本地球馆。

`activity_api`已通过官方MCP部署，130份托管源码逐一匹配，迁移001～005、14条路由和双榜22项在线检查已通过，测试数据已清理。见[源码核对](outputs/prelaunch-20261118/deployed-source-verification.json)、[在线双榜检查](outputs/prelaunch-20261118/live-http-smoke.json)及[清理确认](outputs/prelaunch-20261118/live-cleanup-verified.json)。统计遥测尚未启用。

截至2026年11月18日：单元测试1607项通过、1项原有跳过，渲染测试47文件375项通过，后端14项、严格类型检查与生产构建通过；[多层目录生产烟测](outputs/prelaunch-20261118/production-nested-smoke.json)覆盖练习、开馆、首次功能引导、设置重玩及音频资源，无HTTP或未处理错误。音量降低约25%，独立静态音效模块、预热解码与前导静音裁剪、动画背景缓存及去除逐帧布局测量已完成。

最终生产包已通过[官方H5自动检查](activity/security-review-api.json)，requestId=req-c1f，submissionAllowed=true，无findings。[h5.zip](h5.zip)与审核原包SHA256一致，前端未正式发布。原生虎扑广告、发帖编辑器、账号切换及云档等仍需真机验收。本地烟测使用游客SDK模拟；音效模块HTTP 200，8个样本各解码一次。历史[官方模拟登录A/B验收](outputs/home-timeflow-20261117/review/live-page-e2e/report.json)和旧包审核不能替代本轮验收。
