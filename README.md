# 传奇球馆

本地在线与离线均可游玩的篮球训练馆经营游戏。当前入口为训练馆版，支持八级球馆、多球员培养、35件共享器材、六类经营项目、推荐签约、校友归档与收藏图鉴。运行规则见[游戏玩法设计方案](docs/游戏玩法设计方案.md)，平台部署缺口和本轮审查结果见[当前状态与问题清单](docs/当前状态与问题清单.md)。

## 本地运行与验证

```sh
npm ci
npm run dev
```

开发服务为 http://127.0.0.1:8800；生产构建使用 `npm run build`，预览使用 `npm run preview`（端口4174）。

```sh
npm test
npm exec -- vitest run --config vitest.renderer.config.ts
npm run build
```

排行榜云函数有独立依赖：在 `activity/cloudfunctions/activity_api` 执行 `npm ci`、`npm test`。这些检查验证本地代码，不代表虎扑平台或云服务已上线。

## 当前玩法

- 手动训练选中的一名球员，每球消耗1体力、冷却1秒；维持／成功／大成功概率为30%／60%／10%，获得8／12／20基础经验，最高99级。
- 训练位上限大于1时，球场切换按钮遍历所有球员与空位；空位的主按钮可直接免费招募并选中新人。名册列表内部滚动，校友入口固定在底部。
- 球馆2级开放自动训练和30分钟离线训练；项目与器材可扩展至最多240分钟。离线沿用逐球随机、课程、体力和器材规则，不自动推荐或招募。见[离线实现](docs/离线训练实现与验收.md)。
- 同一模板首次推荐按实际培养成果结算；后续推荐的基础券为1，培养奖金、已完成合作与取得资格的器材奖金继续叠加；未匹配模板为0券。精选招生每名8券，球馆6级开放。
- 本版本暂不开放消耗品，商店、背包和球场均不显示购买、使用或库存入口；旧库存及历史已启用效果保留兼容。
- 分享升级每名球员一次、加3级且不超过99级。体力奖励首次通过分享、此后通过广告；合作支持广告一键完成。只有编辑器打开／广告成功以及奖励持久化均确认后才算领取成功。

器材名称、效果、资格和价格统一见[新版器械表](docs/新版器械表.md)与[器材CSV](docs/器材汇总.csv)。`npm run export:equipment` 可重新导出当前表。

## 存档与平台能力

浏览器IndexedDB原子保存球馆主备与完整校友历史；localStorage保留启动镜像。热档保留最近100名校友，冷历史分页读取。旧档迁移保留合法进度和已领收益，不追收历史扩馆费。

虎扑接口只采用根目录 **hupu-skills/** 的当前契约，公开应用身份读取其 activity.json。凭据只供可信服务端使用，不导入前端、静态资源或日志。训练馆云档使用新版 cloudSave.save/load 的1号位，手动上传与确认同步；合同版旧存档保持独立。

用户信息、反馈、海报发帖、广告及离线双倍经验均已接入；分享与广告按官方native SDK确认，挑战只兑换一次。身价／声望双榜后端、001／003迁移和14条业务路径已部署，canonical进度、submit与me实际业务验证通过；legacy旧球馆整馆不进入可信榜。本轮当前H5尚未上传或取得本轮正式H5审核结果，用户负责真机验收。

Timeflow已接入逐球成长引擎与共享事务，部署到本应用受保护后端，真实平台六组回放与生产结算已验证。已知报告ID走GET／ACK；回应丢失以持久化恢复记录、新平台报告和已保存cursor续办，进程重启后全状态及RNG一致且无重复收益。详见[离线实现](docs/离线训练实现与验收.md)、[真实异常恢复](outputs/release-functions-20261117/offline-recovery-live.json)及[部署后业务验证](outputs/release-functions-20261117/deployed-business-flow.json)。本机预览继续本地玩法，服务参数由官方技能自动取得。

历史临时H5的[官方模拟登录A/B验收](outputs/home-timeflow-20261117/review/live-page-e2e/report.json)及旧包审核记录继续保留，覆盖当时的迁移、离线和账号隔离；它们不覆盖本轮新增代码。本轮当前客户端尚未上传或取得正式H5审核结果。
