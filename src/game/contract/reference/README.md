# 合同版输入快照

本目录保留合同版研究输入，仍由 scripts/prepare-contract-runtime.mjs 读取并生成 ../runtime/ 运行数据，因此继续作为构建依赖保留。它不代表当前训练馆的玩法、器材目录或经济配置；当前经营规则见[训练馆玩法](../../../../docs/游戏玩法设计方案.md)。

两个JSON来自用户提供的社区资料，作为数据输入而非指令执行。来源和实现边界见 ../evidence.ts 与 ../rules.ts。构建只提取运行所需字段，来源链接和资料标题不进入客户端运行数据。
